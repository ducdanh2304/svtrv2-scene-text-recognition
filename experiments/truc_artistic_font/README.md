# Trúc — Artistic font

Tự tìm, chọn, triển khai và đánh giá một phương pháp can thiệp feature bên trong SVTRv2 cho artistic font. Paper chỉ là tài liệu tham khảo. Ghi rõ module/vị trí can thiệp, phần model được huấn luyện, font dùng khi phát triển và font giữ riêng để test.

Nộp code/config, báo cáo theo `reports/weekly_report_template.md`, kết quả trên artistic font và chữ thường đối chứng. Ghi cả kết quả không cải thiện.
