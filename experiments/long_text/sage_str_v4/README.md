# Kaggle reproduction — SAGE-STR v4

The canonical executable experiment is [`notebooks/SAGE_STR_v4_Kaggle_RunAll.ipynb`](notebooks/SAGE_STR_v4_Kaggle_RunAll.ipynb), **the exact notebook run in the pilot**. The `src/` tree contains the same source generated by its `%%writefile` cells, extracted without changing the algorithms, for code review and testing.

**Start:** Kaggle Code → New Notebook → import `.ipynb` → GPU on → Internet on for dependency/data downloads → Run All. Set `MAX_LTB=1200` and `MAX_EXTERNAL=256` for the original development pilot; `0` for each means the corresponding full available cohort. Runtime outputs go to `/kaggle/working/SAGE_STR_V4_GPU_RESULTS` and an optional ZIP is written to `/kaggle/working/SAGE_STR_V4_GPU_RESULTS.zip`. All main tables print in the notebook; no ZIP download is necessary.

The notebook obtains **official frozen SVTRv2-T**, clones **OpenOCR commit `1ccfc6ee6161f7133b192e16af3a9265273997ba`**, verifies checkpoint/config SHA256, reads LTB and Union14M/IIIT5K/CUTE80, builds shared candidate predictions, trains separate selector/calibration models with stable hash splits, evaluates v3 control vs v4, and writes forensic trace. This is **not fully training-free**, because the selector learns on labels.

## Source layout

- `src/longtext_final.py`, `longtext_v3.py`: raw-image overlapping crops and geometry-aware CTC stitching.
- `src/orientation_probe.py`, `density_probe.py`, `unified_router.py`: candidate generators and historical Unified v1 control.
- `src/sage_gpu_adapter.py`: GT-blind interface between frozen recognizer and candidate evidence.
- `src/sage_str_v2/`: shared hypothesis contract and CTC evidence.
- `src/sage_str_v3/`: reproducibility control.
- `src/sage_str_v4/`: contextual dual-arbiter model and batch scorer.
- `artifacts/*.joblib`: small selectors produced by the **reported GPU pilot**, for trusted forensic analysis only. **Joblib uses pickle; never load artifacts from untrusted sources.** They are not SVTRv2-T checkpoint weights.
- `scripts/`: parity and metric-recalculation checks, runnable on CPU.

## Verify locally without GPU

From this folder:

```bash
python scripts/verify_source_parity.py
python scripts/verify_pilot_metrics.py
python -m unittest discover -s tests -v
```

Tests validate source identity, pilot evaluation metrics from per-image predictions and selector invariants. They **do not substitute for GPU reproduction** of OpenOCR. `pip install -r requirements-selector.txt` installs dependencies of the lightweight selector (not the full GPU OCR stack).

## Known scientific limitations

The 461-image evaluation is disjoint *within this run* but sources were repeatedly used for development; it is not independent held-out generalization. The fixed hash split is invariant to cohort cap, but the selector is re-trained when the cohort changes; a full-cohort result is not automatically a valid untouched test. CPU tests do not establish runtime/VRAM claims. The audit is empirical rather than a formal risk guarantee. See [limitations](../../../reports/long_text/sage_str_v4/03_KET_QUA_VA_GIOI_HAN.md).
